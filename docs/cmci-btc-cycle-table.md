## 4. 必须保留的解释限制

1. **样本量**：4 个已闭合减半区间加 1 个进行中区间，是事件聚类样本，不能当作独立宏观周期。不得用滚动窗口数量冒充独立周期数。
2. **宏观字段缺失**：任务三要求利率、美元、全球流动性和金融压力字段；L1 尚未接入，本版全部留空，不能用当前修订值补齐。
3. **价格口径**：BTC/USD 为单一交易场所参考序列，不是全球指数；2014 年前数据缺失。
4. **结构性变量**：ETF、稳定币在早期周期并不存在，缺失记为“不适用”，不补零、不向前外推。
5. **减半与四年周期**：本表只描述减半事件及其后价格，不证明“四年周期”假说成立。
