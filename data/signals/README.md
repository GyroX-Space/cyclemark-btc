# Daily Signal Archive

This directory is reserved for versioned daily CycleMark state records.

No live signal or historical state is included in the initial release. Do not add illustrative data here without clearly separating it from verified records.

Each published record should include the observation date, generation timestamp, model version, BFS, BOS, state, input coverage, feature values or references, data-source timestamps, and an explanation of any state transition.

Historical records must preserve what was knowable at publication time. Corrections should create a traceable revision rather than silently rewriting the historical record.
